# Разбег

Локальный прототип сопровождения первых недель работы. Все сотрудники, обращения и корпоративные ответы вымышлены.

## Запуск

Node.js 22.12 или новее. `npm ci`, затем `npm run dev`. Скрипт сам запускает API с необходимым флагом SQLite и Vite.

Интерфейс: http://localhost:5173/. API: http://127.0.0.1:4310. Оба процесса слушают только loopback. Данные сохраняются в `data/novichok.sqlite`, перезапуск их не удаляет. Остановка: Ctrl+C. Сброс учебных данных — через «О демо» с подтверждением.

## Что проверить

1. HR → «Маршруты»: общий редактируемый план по должности; описание вакансии или документ → предложение плана → проверка HR → сохранение.
2. HR → «Добавить новичка»: назначение существующего маршрута; необязательное резюме PDF, DOC или DOCX с предпросмотром извлечённого текста.
3. Сотрудник → «Мой день»: выполнение шагов, короткий опрос и обращение за помощью. У сотрудников с одним маршрутом независимый прогресс.
4. «Ответы»: поиск опубликованных ответов → «Да, помогло» или передача вопроса человеку. Неудачные попытки сохраняются вместе с обращением.
5. HR / руководитель: сообщение, действие, ответственный и срок → «Сделано → проверить». Сотрудник подтверждает результат либо возвращает вопрос в работу.
6. HR может подготовить обобщённый ответ из обращения. Публикация требует отдельной проверки; личная переписка автоматически в базу не попадает.

Верхняя панель переключает демонстрационные роли. Это не настоящая авторизация. Для обращения напрямую HR текст не включается в представление наставника, но открытый переключатель ролей означает, что прототип предназначен только для вымышленных данных.

## Документы и ограничения

Документы разбираются на этом компьютере, без облачной отправки. Оригинал и извлечённый текст резюме не сохраняются. Описание вакансии сохраняется при сохранении маршрута. Лимит — 8 МБ, PDF до 40 страниц; PDF без текстового слоя требует OCR, который не подключён.

Предложение маршрута и поиск ответов работают по правилам и ключевым словам. Внешняя языковая модель, Битрикс24, рассылки и уведомления не подключены. Автоматического чтения задач заказчика нет. Шаблоны — примеры для проверки HR, а не установленные правила реальной компании.

Редактирование общего маршрута меняет его для назначенных сотрудников. Неизменённые шаги сохраняют прогресс; изменённые шаги требуют повторной отметки. История опросов сохраняет исходные формулировки вопросов.

Локальный запуск использует SQLite. Vercel использует постоянную базу Neon Postgres: состояние обновляется атомарно с проверкой версии, параллельные изменения не затирают друг друга. В облаке сохраняются только учебные данные; это общая демонстрация с открытым переключением ролей. Для реальных сотрудников необходима настоящая авторизация.

## Проверки

- `npm test` — 47 проверок (включая 9 проверок облачного адаптера и 4 инфраструктурного шаблона) доменной логики, изоляции представлений и разбора настоящих PDF/DOC/DOCX, включая кириллицу и некорректные файлы.
- `npm run typecheck` — TypeScript.
- `npm run build` — сборка.
- `npm run test:sites` — 4 проверки сохранённого инфраструктурного шаблона; это не проверка облачного развёртывания.

Основной цикл обращения, повторное использование опубликованного ответа другим сотрудником, загрузка трёх форматов и сохранность после перезапуска проверены в браузере и через локальный HTTP API. Визуальная проверка: `design-qa.md`. Нагрузочные испытания, настоящий HR-пилот и снижение текучести не проверялись.

## Vercel

- Исходники: https://github.com/NIKFIRE4/razbeg-onboarding (публичный репозиторий).
- Vercel Functions в `api/` используют тот же HTTP-контракт, что локальный сервер.
- Создайте Neon на бесплатном тарифе и подключите `DATABASE_URL` к окружению preview. Не добавляйте этот секрет в Git.
- Однократно: `node --env-file=.env.local scripts/init-cloud-db.mjs`. Инициализация сохраняет уже существующие данные.
- `vercel deploy --yes` создаёт preview-развёртывание; автоматическое развёртывание Git отключено в `vercel.json`.
- Облачный лимит документа — 3 МБ (JSON с base64 укладывается в лимит Vercel); локальный — 8 МБ. Облачный файл разбирается на сервере Vercel и не сохраняется.
- Облачная база общая для демонстрации. Сброс данных влияет на всех посетителей и требует явного подтверждения.
- Внешняя ИИ-модель и Битрикс24 не подключены.
